01Context, not guesswork.The incident recorder

A fault is a moment.
The story is
on either side.

A strange idle. A sudden hesitation. Something you felt, but can’t make happen again.

DRIFTER VIM is a Raspberry Pi vehicle computer. It keeps a rolling record of supported OBD-II data, then preserves a window around an automatic or manual incident capture.

The point isn’t to guess which part broke. It’s to give the investigation something to work with.

Before you join.

Is this a finished product I can buy?

Not yet. This is a field-testing programme for a hardware-integrated prototype. There is no checkout, delivery promise or finished hardware kit on this site. The immediate aim is repeatable operation and useful incident evidence.

What hardware is involved?

The reference setup uses a Raspberry Pi 5, storage, a display or browser interface, suitable power and an appropriate OBD adapter. The Pi is the computer; the adapter is the vehicle connection. See the tester guide for the current setup.

Will it work with my car?

The target is standards-based OBD-II data. Actual support depends on your vehicle’s protocol, adapter and available PIDs. The Jaguar is the reference platform; another combination needs its own evidence. The field-testing application asks for your exact setup.

Does the recorder need the cloud?

The core vehicle telemetry, deterministic rules, logging and incident capture run locally. Optional online services and AI-assisted features are separate from that core recording path.
