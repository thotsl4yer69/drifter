DRIFTER VIM

Vehicle Intelligence Module — a dedicated Raspberry Pi vehicle computer for OBD-II telemetry, diagnostics, drive logging and incident evidence capture.

The launch story:

The fault vanished. The evidence didn't. DRIFTER's incident black box can preserve a bounded 90-second pre-event window and 45-second post-event tail around an automatic or manual capture.

What is demonstrated

Hardware-integrated Pi nodeRaspberry Pi/Linux deployed in the vehicle-node role.
OBD-II telemetry architectureELM327/legacy OBD transports plus SocketCAN-oriented paths.
Incident evidencePre/post event capture, ordered sensor changes and deterministic correlation flags.
Touchscreen field workflowAdapter, ECU and live-PID states shown separately.
Drive loggingSession data and post-drive evidence pipeline.
Safe update pathConservative updater defers while telemetry indicates vehicle activity and can roll back failed deployments.

Current status

Hardware-integrated prototype / active hardening. Primary physical validation is on a 2004 Jaguar X-Type 2.5L V6. The system targets standards-based OBD-II vehicles, but compatibility is recorded only from real vehicle + adapter evidence.

This is a founding beta, not a production-readiness claim.

Primary acceptance gate

  • 10/10 cold boots from intended vehicle power;
  • stable 30-minute Jaguar RPM/coolant/speed/voltage telemetry;
  • ELM327 unplug/replug recovery or explicit actionable failure;
  • display recovery without full power cycling where Linux remains alive;
  • useful incident bundle and field evidence after a fault.
