# DRIFTER VIM / Field Recorder 01.2

## Visual authority

Continue the selected Field Recorder design. Do not revert to the original neon dashboard-card website. The canonical homepage is `home-source.html`; its foundation is `brand-base.css`. Shared pages use `pages.mjs` and `complete.css`. `recorder-runtime.js` owns the original time ribbon. `site.js` owns shared interactions.

Paper `#EEEDE6` and warm ink `#151713` are the primary surfaces. Muted olive-grey supports text and technical rules. Amber `#FFB640` is a marker for time, not an indiscriminate decoration. Use the supplied geometric wordmark paths, without stretching them. Keep serif italics for restrained editorial contrast and monospace for short technical labels. No font files are distributed.

## Purpose

“A memory for your machine.” A persistent vehicle node can retain the context around an intermittent fault. The website should explain that distinction, help a tester describe a real setup, and make useful reporting possible. The company endorsement is MAZLABZ; the product is DRIFTER VIM, expanded as Vehicle Intelligence Module.

## Assets

`assets.mjs` generates twelve original SVG files deterministically from the existing wordmark. These include positive/inverse marks, project signature, profile symbol, campaign pieces, a vertical invitation, recorder illustration, architecture illustration and identity sheet. The asset ledger on the media page describes formats. The media ZIP contains the vectors, two finished PDFs, palette and usage notes. PNG buttons render the original SVG in the browser. Campaign artwork was also imported into the dedicated DRIFTER Canva folder.

## What not to add

Do not add stock supercars, invented circuit boards or finished product housings. Do not invent reviews, users, sales, follower counts, live telemetry or compatibility results. Do not confuse a conceptual connection-state demonstration with a connected ECU. Do not add pricing, checkout or shipping promises for an unvalidated hardware kit.

## State and motion

The ribbon is explicitly illustrative. No autoplay is required. It uses cached static geometry during playback, a bounded before/event/after sequence and an amber scrubber. Reduced-motion preferences use static chapter changes. Keep actual content visible without JavaScript; retain ordinary page navigation and email links.

## Content and evidence

The source date is a snapshot, not a live feed. Engineering facts are linked to the repository and issue #67; open records are not converted into passed checks. The field worksheet starts at Not tested and exports USER-REPORTED data. Applications prepare or copy an email; they do not pretend to submit to a server. Keep those boundaries precise without turning the website into repetitive warnings.
