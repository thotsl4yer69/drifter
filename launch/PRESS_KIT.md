# DRIFTER VIM — Public Messaging & Press Kit

## Boilerplate

DRIFTER VIM is a Raspberry Pi-based vehicle intelligence module developed by MAZLABZ. It is designed as a dedicated local node for OBD-II telemetry, touchscreen diagnostics, drive logging and incident evidence capture. The system is currently a hardware-integrated prototype in active field hardening, with the 2004 Jaguar X-Type as its primary validation vehicle.

## Product facts safe to publish now

- Raspberry Pi/Linux vehicle-node architecture.
- OBD-II telemetry paths using ELM327/legacy OBD transports and SocketCAN-oriented integration.
- MQTT-based internal service communication.
- Touchscreen vehicle setup and link-state workflow.
- Deterministic diagnostic processing and drive logging.
- Incident capture with a bounded 90-second pre-fault window and 45-second post-fault tail.
- Manual and automatic incident capture.
- Ordered sensor-change evidence and correlation flags.
- Conservative self-update path that can defer while the vehicle is active.
- Primary validation platform: 2004 Jaguar X-Type 2.5L V6.
